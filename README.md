# notes-api

[![CI](https://github.com/marcus-beauregard/notes-api/actions/workflows/ci.yml/badge.svg)](https://github.com/marcus-beauregard/notes-api/actions/workflows/ci.yml) [![License: GPL-2.0-or-later](https://img.shields.io/badge/license-GPL--2.0--or--later-blue.svg)](LICENSE)

A REST API for notes: Express + better-sqlite3. Supports list (paginated),
create, read, and delete. Intended as a compact backend for small apps.

## Contributing

Humans and automated agents are both welcome. There is no CLA — every commit carries a [DCO](https://developercertificate.org/) sign-off (**git commit -s**). Start with a [good first issue](https://github.com/marcus-beauregard/notes-api/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or read [CONTRIBUTING.md](CONTRIBUTING.md).
